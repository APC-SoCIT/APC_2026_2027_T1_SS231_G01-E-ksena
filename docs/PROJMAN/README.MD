## 📊 4. Earned Value Management (EVM)
Metrics calculated for Sprint 1 only.

### Core Values
- Planned Value (PV): Php Insert Value
- Earned Value (EV): Php Insert Value
- Actual Cost (AC): Php Insert Value

### Performance Indices and Variances
- Cost Variance (CV): $CV = EV - AC$ (Result: Insert Value)
- Schedule Variance (SV): $SV = EV - PV$ (Result: Insert Value)
- Cost Performance Index (CPI): $CPI = \frac{EV}{AC}$ (Result: Insert Value)
- Schedule Performance Index (SPI): $SPI = \frac{EV}{PV}$ (Result: Insert Value)
